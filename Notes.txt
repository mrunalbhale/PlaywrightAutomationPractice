Interception of an API response - Identify at what step we are getting a response.
So before that step, try to fake it. Method used to fake a response - route().
route("url for which we want to fake a response",
 async route =>{
    get actual response,
    get the fake body,
    route.fulfill({
        original response
        fake body in json format
    })
 }
)

---------------------------------playwright.config.ts file options------------------------------------------
viewport:{width:720,height:720}
property to be added in playwright.config.ts to change the dimenssions of the screen that will be opened when the browser launches.
{
      name: 'Mobile Safari',
      use: { ...devices['iPhone 15 Pro Max'] },
}-- write ...devices[] and it will give us a list of mobile devices available and the script will run on the screen having dimenssions similar to that mobile device.
